The world's news of Sunday 22 November 2026 on one front page: COP31's final deal rejected in Antalya, a Russian drone
strike that left 14 missing in a block of flats near Kyiv, the candy-factory fire in Indonesia, South Korea's education
minister resigning over AI exam cheating, and more, each checked against the date and placed on a map.

- `src/page.html`: the layout, hand-written HTML/SVG (maps and icons are original vector drawings)
- `src/render.mjs`: renders the page to `entry.png` (1024×1024) with headless Chrome
- `main.ts`: the entry program; it copies `entry.png` to the output directory

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
